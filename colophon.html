About This Website

This website is a student project created for the Introduction to Web Technologies course. It serves as an informative online platform dedicated to the Saken Seifullin Museum in Astana.

Development Team (3 Members)

  • Student 1: Project Manager & Lead Content Developer (Handled HTML Structure, Biography, Home page)
  • Student 2: Technical Designer & Forms Specialist (Handled Exhibits, Feedback, and Contacts)
  • Student 3: Quality Assurance & Media Specialist (Handled Exhibitions, Gallery, Colophon, and W3C Validation)

Technical Specifications

The website is built following strict semantic HTML5 rules without external frameworks or styling libraries:

  • Pure semantic HTML5 markup.
  • Valid HTML structure adhering to W3C standards.
  • Accessible media elements with descriptive alt attributes.
